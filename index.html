Data Science

9 projects

Most software solely moves data around. Data science is about understanding what the data actually means. This track starts with the fundamentals — loading, cleaning, and visualizing datasets — and builds toward training and deploying real machine learning models. I'm learning how to ask the right questions before touching a dataset, how to engineer features that give models a fighting chance, and how to evaluate results honestly rather than just chasing accuracy scores. Projects span EDA, regression, NLP sentiment analysis, anomaly detection with isolation forests and LSTMs, and a full MLflow-tracked experiment pipeline.

Pythonpandasmatplotlib scikit-learnXGBoostPyTorch HuggingFaceMLflowSQL StreamlitPlotlyBeautifulSoup
What this builds toward: the ability to take a raw dataset, identify patterns, build a model, track experiments, and serve predictions through an API — the full loop that data engineering and ML roles expect. Capstone is a live interactive dashboard pulling from a real data source, publicly deployed.

Embedded Systems

8 projects

Most developers never touch the hardware layer. Embedded systems is where software meets the physical world — writing C++ that runs directly on microcontrollers, managing memory manually, and reasoning about timing at the microsecond level. This track covers sensor interfacing over I2C and SPI, hardware interrupts, real-time operating systems with FreeRTOS, RFID access control, and a full IoT pipeline over MQTT. There is no runtime to hold your hand: if the code is wrong, the hardware just does the wrong thing. That constraint forces a precision that makes you a sharper programmer in every other context too.

C++ArduinoESP32 FreeRTOSI2C / SPIMQTT ISRs & TimersDHT22RFID InfluxDBGrafana
What this builds toward: a complete end-to-end IoT pipeline — sensors collecting data, an ESP32 publishing over MQTT, a Python subscriber storing to a time-series database, and a Grafana dashboard visualizing it live. The same architecture used in real industrial monitoring systems.

Full Stack Development

8 projects

Full stack means owning the entire user-facing layer of a product — from a React component reacting to a click, to the Flask route handling the request, to the PostgreSQL schema storing the result, to the Docker container shipping it to production. This track is intentionally practical: I'm building things I'd actually want to use — a job tracker for my own internship search, a real-time group chat over WebSockets, and an authentication system with JWT tokens and proper password hashing. The capstone involves containerizing a multi-service app with nginx, Docker Compose, and a deployed ML model behind a REST API.

ReactJavaScriptHTML / CSS FlaskPostgreSQLSQLite REST APIsWebSocketsJWT / bcrypt DockernginxPostman
What this builds toward: the ability to architect, build, secure, and deploy a complete web application independently — not just "I know React," but understanding how all the layers talk to each other and where things break under real conditions.
