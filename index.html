Data Science

9 projects

Most software moves data around. Data science is about understanding what the data actually means. This track starts with EDA and builds toward deploying real ML models — regression, NLP sentiment analysis, anomaly detection with isolation forests and LSTMs, and a full MLflow-tracked experiment pipeline. I'm learning to ask the right questions before touching a dataset, engineer features that give models a fighting chance, and evaluate results honestly rather than chasing accuracy scores.

Embedded Systems

8 projects

Most developers never touch the hardware layer. Embedded is where software meets the physical world — C++ running directly on microcontrollers, memory managed manually, timing reasoned at the microsecond level. This track covers sensor interfacing over I2C and SPI, hardware interrupts, FreeRTOS, RFID access control, and a full IoT pipeline over MQTT. No runtime to hold your hand: if the code is wrong, the hardware just does the wrong thing. That constraint forces a precision that sharpens you everywhere else.

C++ArduinoESP32 FreeRTOSI2C / SPIMQTT ISRs & TimersDHT22RFID InfluxDBGrafana
Builds toward: sensors → ESP32 → MQTT → time-series DB → live Grafana dashboard. The same architecture used in real industrial monitoring.

Full Stack

8 projects

Full stack means owning the entire user-facing layer — from a React component reacting to a click, to the Flask route handling the request, to the PostgreSQL schema storing the result, to the Docker container shipping it. This track is intentionally practical: a job tracker for my own internship search, a real-time chat over WebSockets, and an auth system with JWT tokens and proper password hashing. Capstone: containerized multi-service app with nginx, Docker Compose, and a deployed ML model behind a REST API.

ReactJavaScriptHTML / CSS FlaskPostgreSQLSQLite REST APIsWebSocketsJWT / bcrypt DockernginxPostman
Builds toward: architect, build, secure, and deploy a complete web app independently — understanding how all layers talk to each other and where things break.
